    QUANDO PRECISAR

    Vamos por partes.

    As respostas essenciais, sem complicação.

    Como receber ajuda?

    Em Início, selecione Abrir meu código. Envie o código exibido para a pessoa que vai ajudar. Quando a solicitação chegar, escolha se ela poderá apenas visualizar ou também controlar.

    Como acessar um dispositivo?

    Peça para o cliente abrir o VoaDesk, digite o código e selecione Solicitar acesso. Aguarde a autorização e a escolha da tela no computador do cliente.

    Como interromper um atendimento?

    Selecione Encerrar atendimento em qualquer uma das pontas. Para liberar o teclado remoto sem encerrar, pressione Escape.

    O que esta versão precisa?

    Esta prévia atende computadores Windows na mesma rede local, com internet para sinalização. O cliente precisa selecionar um monitor SDR. Aplicativos elevados e conexões entre redes diferentes não têm suporte validado.
