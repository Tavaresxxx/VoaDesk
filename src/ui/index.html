      QUANDO PRECISAR

      Vamos por partes.

      As respostas essenciais, sem complicação.

      Como receber ajuda?

      Em Início, selecione Abrir meu código. Envie o código exibido para a pessoa que vai ajudar. Quando a solicitação chegar, clique em Aceitar conexão para autorizar controle, acesso aos monitores e transferência de arquivos.

      Como acessar um dispositivo?

      Peça para o cliente abrir o VoaDesk, digite o código e selecione Solicitar acesso. Aguarde a autorização. Depois, use a barra do atendimento para trocar de monitor.

      Como buscar um cliente?

      Na tela inicial, digite o nome ou parte do código de um cliente salvo. A busca aceita nomes com ou sem acentos e códigos com espaços ou hífens. Use Buscar em para filtrar por nome ou código; cada sugestão mostra como foi encontrada. Se houver mais de seis resultados, Ver todos abre a lista completa e mantém a consulta e o filtro. Selecione com o mouse ou com as setas e Enter; depois escolha Solicitar acesso. Buscar não envia solicitações nem consulta outros computadores.

      Como testar sozinho nesta máquina?

      Em Início, selecione Testar nesta máquina. Uma tela simulada permite digitar no bloco de notas, arrastar sua janela, clicar no contador, desenhar e rolar o conteúdo. Vídeo e comandos passam por WebRTC local. Reiniciar teste apaga as atividades; Sair do teste encerra a conexão. Esse modo não captura o Windows e não valida acesso entre computadores.

      Como interromper um atendimento?

      Selecione Encerrar atendimento em qualquer uma das pontas. Para liberar o teclado remoto sem encerrar, pressione Escape.

      O que esta versão precisa?

      Esta prévia atende computadores Windows na mesma rede local, com internet para sinalização. Os monitores do cliente precisam operar em SDR. Aplicativos elevados e conexões entre redes diferentes não têm suporte validado.
